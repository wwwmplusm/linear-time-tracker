Конфиденциальность расширения «Личный таймер для Linear»

Расширение показывает таймеры и журнал на страницах проектов и задач Linear. Для работы нужен совместимый сервер трекера, который вы настраиваете самостоятельно.

Какие данные обрабатываются

Расширение передаёт выбранному вами серверу адрес текущей задачи или проекта Linear без параметров и фрагмента. При использовании элементов управления оно также передаёт идентификаторы задач и интервалов, команды таймера и время запуска агента, если вы его ввели. Браузер прикладывает cookie сессии трекера к запросам на этот сервер.

Сервер получает названия, идентификаторы и ссылки объектов через подключённый вами аккаунт Linear. Сервер хранит историю измерений и записи запусков агентов. При настройке интеграции сервер хранит токены подключения к Linear. Расширение хранит адрес сервера локально в браузере.

При переходе в проект из трекера расширение использует адреса открытых вкладок Linear, чтобы открыть проект в подходящей вкладке. По команде «Завершить задачу в Linear» сервер обновляет статус задачи, связанной с сохранённой записью времени.

Для чего используются данные

Данные нужны для определения открытой карточки, синхронизации таймеров и показа журнала. Расширение не содержит рекламы и аналитики. Оно отправляет данные таймеров только на указанный вами сервер. Издатель не продаёт эти данные и не использует их для рекламы.

Управление данными

Удаление расширения прекращает отправку запросов и удаляет сохранённый в нём адрес. Данные на сервере остаются под управлением его владельца. Удаление записей и резервных копий выполняется на сервере. Доступ к Linear можно отозвать в настройках рабочего пространства Linear.

Вопросы об обработке данных можно направить через контакт разработчика, указанный на странице расширения в Chrome Web Store.
